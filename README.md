# nuxt on deno

Пример nuxt на deno для Timeweb Cloud Apps.

## Параметры деплоя

| Параметр | Значение |
| --- | --- |
| Runtime | `deno` |
| Фреймворк в API | `nuxt` |
| Тип приложения | `frontend` |
| Команда сборки | `deno task build` |
| Директория сборки | `.output/public` |

## Локальный запуск

```bash
deno install --allow-scripts
deno task build
```
